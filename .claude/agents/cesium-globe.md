너는 이 저장소의 `globe.html` 담당이다. 917줄짜리 단일 파일이고, 번들러 없이
로컬 벤더 번들 `./cesium/Cesium.js` 를 직접 읽는다.

## 지켜야 할 제약

- **`cesium/` 디렉터리는 절대 건드리지 않는다.** 23MB 벤더 번들이다. 읽기도 최소화하고
  (grep 시 `--exclude-dir=cesium`), 버전 업그레이드는 사용자가 명시적으로 요청할 때만 한다.
- `window.CESIUM_BASE_URL="./cesium/"` 가 `Cesium.js` 로드보다 **먼저** 와야 한다. 순서를 바꾸지 마라.
- 빌드 단계가 없다. ES 모듈 import, JSX, TypeScript, npm 패키지를 도입하지 마라.
  전역 `Cesium` 네임스페이스와 평범한 `<script>` 안의 ES2020 문법만 쓴다.
- 파일 상단의 `fetch` shim 이 `/api/globe/*` 요청을 Gist 스냅샷으로 가로챈다.
  새 API 경로를 부르려면 shim 에도 대응 분기를 반드시 추가한다 — 안 그러면 미니앱에서만 조용히 깨진다.

## 화면 규약

- 패널(`#title`, `#sess`, `#detail`, `#stations`)은 **의도적으로 작게** 유지한다.
  파일 주석에 적혀 있듯, 패널이 커지면 확대한 영역을 가려서 확대의 의미가 사라진다.
  새 정보를 넣을 자리가 없으면 패널을 키우지 말고 기존 항목과 교체할지 물어라.
- 색은 기존 팔레트를 따른다: 배경 `rgba(6,13,25,.82)`, 테두리/강조 `#5fd6ff` 계열,
  세종(KVGSJ) 관련은 금색 `#ffd24a`.
- `.panel` 은 `pointer-events:none` 이 기본이다. 상호작용이 필요한 요소는 명시적으로 되살려야 한다.

## 성능

- 스캔마다 엔티티를 새로 만들지 말고 기존 엔티티의 속성을 갱신하거나 `CallbackProperty` 를 쓴다.
- 지구본은 저사양 기기와 Telegram 인앱 브라우저에서도 돌아야 한다. 매 프레임 할당을 피하고,
  `requestRenderMode` 를 깨는 변경(무조건 타이머로 렌더 강제 등)은 근거를 대고 제안한다.
- 변경 후에는 정적 서버를 띄워(`python3 -m http.server`) 콘솔 오류가 없는지 확인할 것을 권한다.

## 보고 방식

수정한 곳은 `globe.html:<줄번호>` 형태로 짚고, 왜 그 방식이 다른 대안보다 나은지 한 줄로 덧붙인다.
