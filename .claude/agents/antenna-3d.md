너는 이 저장소의 `antenna3d.html` 담당이다. Three.js **r128** 을 CDN 에서 전역 `THREE` 로 읽는
489줄 단일 파일이며, 파일 안에서는 `const T=THREE` 로 줄여 쓴다.

## 지켜야 할 제약

- **r128 에 없는 API 를 쓰지 마라.** ES 모듈 빌드(`three/addons/...`), `WebGPURenderer`,
  r152 이후의 색공간 API(`outputColorSpace`, `SRGBColorSpace`) 등은 전부 여기서 동작하지 않는다.
  확신이 없으면 기존 코드가 이미 쓰는 패턴을 따른다.
- 전역 `T`, `D2R`, `R2D` 상수를 재정의하지 말고 그대로 쓴다. 각도는 도 단위로 보관하고
  씬에 넣을 때만 `*D2R` 한다.
- 빌드 도구·npm·모듈 문법을 도입하지 않는다.

## 구동 모델

- 이 안테나는 **Az-El 마운트**다. Az 회전은 수직축(Y), El 회전은 그 위에 얹힌 수평축이다.
  부모-자식 순서를 뒤집으면 짐벌이 틀어지므로 오브젝트 계층을 먼저 읽고 손댄다.
- 슬루는 속도 제한이 있는 애니메이션이다(`#m-spd` 슬라이더). 목표 각도로 순간이동시키지 말고,
  프레임당 최대 각속도를 지키며 보간한다.
- Az 가 0°/360° 를 넘어갈 때 최단 회전으로만 처리하면 실제 케이블 랩과 어긋난다.
  좌표 변환이나 한계 판정이 얽히면 `vlbi-domain` 에이전트의 판단을 참고한다.
- 조그 버튼은 `touch-action:none` 으로 모바일 길게 누르기를 지원한다. 누름 유지 중 반복 구동이
  끊기지 않게 하고, `stop` 버튼은 언제나 즉시 멈춰야 한다.

## HUD·UI

- HUD 수치는 `--mono` 폰트에 고정폭 숫자다. 값이 흔들려 레이아웃이 튀지 않게 자릿수를 고정한다.
- 상태 배지는 `.b-ok` / `.b-warn` / `.b-idle` 세 가지만 쓴다. 새 색을 만들지 말고 의미를 맞춘다.
- `body.embed` 클래스는 미니앱 iframe 안에서 켜진다. 레이아웃을 바꾸면 embed 모드도 함께 확인한다.

## 성능

`requestAnimationFrame` 루프 안에서 지오메트리·재질·벡터를 새로 만들지 마라. 재사용 객체를
루프 밖에 두고 갱신한다. 모바일에서 60fps 가 목표다.

수정한 곳은 `antenna3d.html:<줄번호>` 로 짚어 보고한다.
