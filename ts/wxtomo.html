GNSS 위성 신호가 대기를 지나며 늦어지는 양(습윤 지연)을 수백 곳에서 재어 수증기를 3차원으로 되살리고, 가강수량이 쌓이며 움직이는 것을 따라가 10·20·30분 뒤 소나기를 읍면동마다 미리 알립니다. VLBI 가 대류권 지연을 추정하는 방식(사상함수·천정 지연·경도)을 그대로 넓혔습니다. 계산은 이 화면에서 실제로 합니다. 화면 안 모의 — 장비 명령은 없습니다.

준비

설정 바꾼 뒤 '다시 계산'

비 문턱(3.8 mm)과 폭은 시나리오 1 에서만 맞추었고, 시나리오 2·3 은 맞추는 데 쓰지 않은 검증용입니다. 조밀망 잡음은 이동통신 기지국·아파트 옥상의 측지급 수신기를 가정한 값입니다.

쓰는 식

습윤 굴절률 N_wet = k₂′·e/T + k₃·e/T² (k₂′ 22.1 K/hPa · k₃ 3.739·10⁵ K²/hPa) 경사 습윤 지연 SWD = 10⁻⁶ ∫ N_wet ds (국 → 위성, 위 끝 10 km) VLBI·GNSS 식 SWD = m_w(E)·ZWD + m_g(E)·(G_N cos A + G_E sin A) m_w = Niell(1996) 습윤 · m_g = 1/(sin E·tan E + 0.0032) 단층 영상 y = A·x + v, A_ij = 광선 i 가 복셀 j 를 지난 길 최소 Σ w(Aδ − y′)² + λh‖Lh δ‖² + λv‖Lv δ‖² + λ₀‖δ‖² (켤레기울기) 가강수량 PWV = Π·ZWD, Π = 10⁶ / (ρw·Rv·(k₃/Tm + k₂′)), Tm = 70.2 + 0.72·Ts 이동 ∂P/∂t + v·∇P = 0 → 전역 루카스–카나데(되풀이 와핑) 예보 P̂(t+τ) = 옮김[ P(t) + (dP/dt)·min(τ,14분) , v·τ ] p = 1 / (1 + exp(−(P̂ − 3.8 mm)/0.8 mm)) → 주의 ≥ 0.3 · 경보 ≥ 0.6

    한계

    1. 대기는 모의다. 배경 수증기·기온 꼴과 대류 세포의 자람·비·사그라듦은 문헌의 크기(가로 2~4 km, PWV +5~10 mm, 30~60분 앞 증가)를 따른 가우스 모형이다. 실제 구름 물리·얼음·하강 기류는 넣지 않았다.
    2. 광선은 직선이다(고도 15° 위에서는 굽음이 작다). 건조(정수압) 지연은 지상 기압으로 안다고 보고 뺐다.
    3. 조밀망(기지국·옥상 409곳)은 가정이다. 실제 위성기준점은 영역 안에 5곳뿐이다.
    4. 예보는 PWV 만 쓴다. 장마 띠처럼 수증기가 넓게 많은 날은 헛경보가 늘어난다 — 실제로는 레이더·위성·수치예보와 함께 써야 한다.
    5. 지하차도·학교·주차장 자리는 가정이다(이름 '○○'). 세종호수공원·금강 둔치는 실제 자리 근처다.
